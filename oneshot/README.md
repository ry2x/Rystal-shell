# One-shot native applications

This Meson project contains native GTK applications that complement the AGS
shell. They share Matugen's generated GTK palette at `oneshot/style.css`.
That file is generated by Ryprland-dot and intentionally is not versioned here.

## AppLauncher

```sh
meson setup oneshot/build oneshot --prefix="$HOME/.local"
meson compile -C oneshot/build
meson install -C oneshot/build
rypr-app-launcher
```

`rypr-app-launcher` runs only while the launcher is visible. Re-running it
closes the existing launcher; after it closes, the next launch reads the
current Matugen CSS and background image. It preserves application history at
`$XDG_CACHE_HOME/ags/app_history.json`.
